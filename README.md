# Network Inventory System

A Python-based command-line Network Inventory System for managing network devices.

## Features

- Display network devices
- Add new devices
- Search devices by hostname or IP address
- Delete devices
- Update device information
- Validate IP addresses
- Prevent duplicate hostnames
- Prevent duplicate IP addresses
- Save inventory data to JSON
- Export inventory reports to TXT
- Export inventory reports to CSV
- Interactive command-line interface
- Input validation and error handling

## Technologies Used

- Python 3
- JSON
- CSV
- `ipaddress`
- Git / GitHub
